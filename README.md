# Pane
An app for notes with markdown, todo-list, calendar system, link collection and a cheat sheet.

---
## How to run
Please install node.js for your operating system of choice as it is required for running the server application then follow these steps:
1. Clone this repository in your prefered way.
2. Open the "Pane" folder in your terminal.
3. Launch the server with this command.
```sh
node server.js
```

---
## Key Features
Keep in mind the everything is subject to change and so is this list.

### 1. Notes With Markdown Syntax
  You can create .md files with proper markdown similar to Obsidian with vault management.

### 2. To-Do List 
  Create task and with the ability prioritize them in any order you desire, set reminders and pin them.

### 3. Calendar
  Schedule tasks with categories and reminder notifications.

### 4. Cheatsheet (WIP)
  Put items on it and view them when ever needed.

### 5. Link Collection
  Very self explanatory, save links, categorize them, edit and pick your favorites.

### 6. Account Management
  Each account has its own set of data, with the ability to set 2FA as a security measure.
